Privacy & Code Signing Policy

Privacy Guarantee

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Sapira Media Player contains zero telemetry, zero analytics SDKs, zero crash reporters, and zero advertisements. Local audio and video playback operates 100% offline. Optional network requests occur strictly when initiated by the user (opening a direct stream URL, browsing the community Radio Browser directory, resolving an external link via local yt-dlp, or explicitly requesting online .lrc lyrics from LRCLIB).

Code Signing Policy (Windows)

Free code signing on Windows is provided by SignPath.io, certificate by SignPath Foundation.

Committers, Reviewers & Approvers: Valentin Borșan (Creator & Lead Maintainer). Multi-Factor Authentication (2FA/MFA) is enforced across all GitHub and SignPath accounts with build or approval privileges.

All official Windows executables and installers are built reproducibly on clean GitHub-hosted runners directly from public MIT-licensed source code via GitHub Actions.
